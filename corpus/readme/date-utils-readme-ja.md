# koyomi-ts

和暦と日本の祝日を扱うための TypeScript 向け日付処理ライブラリです。日本向けのカレンダー表示や、和暦を使った日付の取り扱いを支援します。

## 主な機能

- **和暦の取り扱い** — 元号を使う日付処理に対応します。
- **日本の祝日の取り扱い** — 祝日を考慮した日付処理に対応します。
- **TypeScript 対応** — 型を活用しながらアプリケーションに組み込めます。

## 活用例

- 申込画面や帳票での和暦の取り扱い
- カレンダー上での祝日の表示
- 祝日を考慮した予定管理

## 日付を扱う際の注意点

### 和暦と元号の境界

改元がある年は、同じ西暦年の途中で元号が変わります。年の数字だけで元号を判断せず、月日を含む日付として扱ってください。

たとえば、2019年4月30日は平成31年、2019年5月1日は令和元年です。

### 祝日と営業日

祝日かどうかと、営業日かどうかは別の条件です。営業日の判定には、土日、会社独自の休業日、年末年始休暇なども考慮してください。

また、振替休日や祝日に挟まれた休日、特例による祝日の移動にも注意が必要です。利用するバージョンが対象年の祝日情報に対応しているか確認してください。

### タイムゾーン

時刻を含むデータでは、タイムゾーンによって日付が変わることがあります。日本の日付として和暦や祝日を扱う場合は、入力データとアプリケーションのタイムゾーンをそろえてください。
