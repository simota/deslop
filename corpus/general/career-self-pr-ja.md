私は、Webアプリケーションのフロントエンドエンジニアとして6年間、React と TypeScript を中心に開発に携わってきました。直近2年間はチームリードとして、開発だけでなくチームの生産性と品質の向上にも取り組んでいます。

**1. React / TypeScript による保守性の高いフロントエンド設計**
React と TypeScript を使い、長く運用できるアプリケーションの設計と実装を担当してきました。型定義を活用してコンポーネントの責務を整理し、状態管理の方針を統一してきました。その結果、仕様変更や機能追加があっても影響範囲を把握しやすいコードベースを作れています。あわせて、パフォーマンスの改善やアクセシビリティへの配慮にも取り組み、ユーザー体験と開発効率の両方を高めることを大切にしています。

**2. チームリードとしての開発プロセス改善**
チームリードとして、〇名規模のチームで技術的な意思決定、タスクの分解と進捗管理、コードレビューを担当しています。レビューの観点やコーディング規約を明文化し、テストや CI を整えることで、メンバーによる品質のばらつきを抑えました。また、プロダクトマネージャーやデザイナー、バックエンドエンジニアと要件の段階から議論し、技術的な制約や代替案を早めに示すことで、手戻りの少ない開発を進めてきました。

**3. メンバーの成長を支える姿勢**
メンバーとは定期的に1on1を行い、それぞれの得意分野や課題に合わせてタスクを割り振っています。設計の意図をドキュメントや勉強会で共有し、特定の人に知識が偏らない体制づくりも進めてきました。若手メンバーが自分で設計を任されるようになるなど、チーム全体の底上げにつなげています。

今後は、これまで培ってきたフロントエンドの技術力とチームリードの経験を活かし、プロダクトの価値向上と強い開発組織づくりの両方に貢献していきたいと考えています。
