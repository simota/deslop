## [2.4.0]

### Added
- Support for locale-aware month and weekday names.
- An option to format dates in UTC.

### Changed
- Improved formatting performance for repeated calls.
- Expanded documentation with examples of custom format strings.

### Fixed
- Corrected zero-padding for single-digit date and time values.
- Fixed handling of escaped characters in format strings.
- Improved consistency when formatting invalid dates.
