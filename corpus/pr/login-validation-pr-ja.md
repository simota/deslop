## 概要

ログイン画面のメールアドレス入力欄に全角文字（例: `ｔｅｓｔ＠ｅｘａｍｐｌｅ．ｃｏｍ`、`テスト@example.com`）が含まれていても、フォームを送信できてしまう不具合を修正しました。

## 原因

メールアドレスのバリデーションが全角文字を弾いていなかったため、不正な形式の値がそのまま送信されていました。

## 変更内容

- メールアドレスのバリデーションを修正し、全角文字（全角英数字・全角記号・かな・漢字など）を含む値をエラーにした
- バリデーションエラー時は送信ボタンを無効にし、送信処理も止めるようにした
- 入力欄の下にエラーメッセージ「メールアドレスは半角英数字で入力してください」を表示するようにした
- 上記ケースのテストを追加した

## 動作確認

| 入力値 | 期待結果 | 確認 |
| --- | --- | --- |
| `user@example.com` | 送信できる | [ ] |
| `ｕｓｅｒ@example.com`（全角英字） | エラー表示、送信不可 | [ ] |
| `user＠example.com`（全角 `@`） | エラー表示、送信不可 | [ ] |
| `user@example．com`（全角 `.`） | エラー表示、送信不可 | [ ] |
| `テスト@example.com`（かな） | エラー表示、送信不可 | [ ] |
| `user@example.com　`（末尾が全角スペース） | エラー表示、送信不可 | [ ] |
| IME で変換確定前の状態 | 確定前にエラーが出たり送信されたりしない | [ ] |

## 影響範囲

- ログイン画面のメールアドレス入力欄のみ
- サーバー側のバリデーションは変更していません
