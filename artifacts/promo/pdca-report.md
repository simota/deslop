## 2. 各サイクルの「Plan → Do → Check → Act」詳細記録

### Cycle 1：初回レンダリング (`v1`) の検証と抜本改善

#### P — Plan（v1 の客観評価：76 / 100点）
`artifacts/promo/previews/v1/` に抽出した代表フレームおよび `ffprobe` 出力を検査し、以下の重大な課題を特定した：
1. **【最優先：タイポグラフィの1文字落ち（Orphan / Widow）】**
   - `v1/10_scene5_climax_contract_ok.png`：大見出し「事実は一文字も捏造しない。コードは一行も壊さない。」の末尾 **`い。`** だけが2行目に落ちていた。さらに右上の `✓ contract_check.py : EXIT 0 (contract ok)` の **`ok)`**、Shield 3 説明文の **`ロ。`**（ゼロのロ）が単独行落ちしていた。
   - `v1/11_scene6_finale_cta.png`：大見出し「責任ある著者が署名できる散文へ。」の末尾 **`へ。`** だけが4行目に落ちていた。
2. **【冒頭0.4秒の視認性不足】**
   - `v1/01_hook_start.png`（0.4秒時点）で右側原稿カードの4行が `opacity: 0.15` と薄く、開始直後に右側が空に見えていた。また左見出し「AIの『水増し』」の中央を横切る取消線が文字と重なりすぎていた。
3. **【Scene 3 ターミナル領域の空白】**
   - `v1/06_scene3_before_redline.png` の右下ターミナルカード中央に不要な黒い空白が生じていた。
4. **【カラースペース・音声ラウドネス】**
   - `ffprobe` で確認したところ JPEG パイプ由来の `pix_fmt=yuvj420p` となっており、音声も平均 `-25.7 dB` と控えめだった。

#### D — Do（v2 への改善実施）
- Scene 5・Scene 6 の全見出し・バッジ・5大保護シールドの説明文に意味単位の明示改行と `white-space: nowrap` を設計し、1文字落ちを根絶。
- Scene 1 の右側原稿カードを0.0秒時点から100%の可読性で表示し、0.35秒〜1.8秒にかけて4本の真紅の取消線（`scaleX(0 -> 1)`）とルールIDバッジが次々と走る演出に変更。
- Scene 3 の右下ターミナルに実際の `detect.py` 出力7行（`JA-06`, `EMO-01`, `CNT-01`, `JA-02`, `ART-04`, `STR-01 cue`, `STR-14 cue`）と `preserve_check` パス行を配置し、空白を解消。
- `render.mjs` に `-vf "format=yuv420p"`、`-color_range tv`、`-af "loudnorm=I=-15:TP=-1.5:LRA=11"` を追加。

#### C — Check（v2 レンダリング結果の検証）
- `v2/10_scene5_climax_contract_ok.png` および `v2/11_scene6_finale_cta.png` にて、1文字落ちがすべて解消されたことを視覚確認。
- `ffprobe` で `pix_fmt=yuv420p`, `color_range=tv` を確認。

#### A — Act（次の課題の特定）
- `v2` でレイアウトと基本品質は85点に到達したが、抽出フレーム検査により新たに3つの課題を発見：

  2. `v2/07_scene3_morph_mid.png`：BeforeとAfterが同じ位置で50%ずつ重なり、13.6秒の中間フレームで文字が二重に見える。
  3. `v2/08_scene3_after_crystallized.png`：右上 `ui-workbench.png` のズーム演出により、左端の1文字（「サ」「DO」）がトリミングされていた。
